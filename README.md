# Wilderlands · 荒野开拓者

> Kenshi 风的种田沙盒 Web 游戏原型。高自由度 + 种田 + 探索 + 沙盒。
> 带领一支三人拓荒小队，砍树、采矿、播种、建据点、打野狼、与游商交易，在荒野里活下来、扎下根。

## 技术栈

- **Vite 5 + TypeScript 5** — 模块化工程与类型安全
- **Three.js 0.160** — 3D 场景渲染（WebGL）
- 零后端，纯前端单页应用；`npm run build` 产物可直接静态托管

## 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（http://localhost:5173）
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 本地预览构建产物（http://localhost:4173）
```

浏览器打开 dev / preview 地址即可游玩（建议桌面端，键盘 + 鼠标操作）。

## 操作方式

| 操作 | 按键 / 鼠标 |
| --- | --- |
| 移动镜头 | `W A S D` |
| 缩放 | 滚轮 |
| 旋转视角 | `Q` / `E`，或按住鼠标中键拖动 |
| 选中角色 | 左键单击角色（`Shift` 多选） |
| 下达命令 | 右键地面 / 实体（树·岩石·农田·商人·野狼） |
| 进食 | `F` |
| 模式切换 | `1` 探索 / `2` 播种 / `3` 围栏 / `4` 木屋 |
| 取消模式 | `Esc` |

## 当前玩法闭环

1. **采集**：右键点树 → 得木材；点岩石 → 得石头。
2. **种田**：`2` 播种模式，右键耕地 → 种下种子；约 12 秒成熟变金黄，右键收获得食物。
3. **建造**：`3` / `4` 模式右键放置围栏与木屋；木屋附近休息可缓慢回血。
4. **战斗**：野狼会游荡并袭击落单的人；右键点狼进入战斗（互相掉血，倒地可复原）。击杀野狼有概率掉肉。
5. **贸易**：右键点游商帐篷打开贸易站——**卖食物 3 金/个、买种子 2 金/个**。
6. **生存**：角色会饿（`F` 进食）、受伤（倒地后会自己爬起）；野狼会随时间刷新。

**可复算的经济闭环**：1 金币买种子 → 收获 2 食物 → 卖出得 6 金币。所有数值集中在 `src/config.ts`。

## 项目结构

```
src/
  config.ts            # 全部数值/色板/命名（as const 单一数据源）
  types.ts             # 领域类型：Tile / 实体 / Unit / 任务
  state.ts             # 全局运行时状态 + 日志注册
  main.ts              # 入口：组装世界、驱动主循环
  core/
    renderer.ts        # 场景 / 相机 / 光照 / 画布挂载
    world.ts           # 地形分区、树木、岩石、商人、农田格
    input.ts           # 键盘 / 鼠标 / 触摸输入
  entities/
    unit.ts            # 单位类（拓荒者与野狼共用，Kenshi 式部位状态）
  systems/
    farm.ts            # 播种 / 生长 / 收获
    build.ts           # 围栏 / 木屋
    combat.ts          # 野狼 AI、战斗结算、刷新
    economy.ts         # 进食 / 饥饿
    commands.ts        # 右键命令分发、拾取、交易触发
  ui/
    hud.ts             # 资源栏 / 选中面板 / 日志 / 模式按钮
    tooltip.ts         # 悬停提示
    trade.ts           # 贸易面板
```

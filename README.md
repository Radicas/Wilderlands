# Wilderlands · 荒野开拓者

> 一款高自由度、带点荒诞的种田生存沙盒 Web 游戏。带领三人拓荒小队砍树、采矿、播种、养点奇怪的东西、打野狼、与游商交易——没有剧情牵着你走，你的目标由你自己定。
> 核心：沙盒 · 种田 · 养殖 · 生存 · 荒诞 · 团队管理。

## 技术栈

- **Vite 5 + TypeScript 5** — 模块化工程与类型安全
- **Three.js 0.160** — 3D 场景渲染（WebGL）
- 零后端，纯前端单页应用；`npm run build` 产物可直接静态托管

## 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（http://localhost:5173）
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 本地预览构建产物（http://localhost:4173）
```

浏览器打开 dev / preview 地址即可游玩（建议桌面端，键盘 + 鼠标操作）。

## 当前玩法闭环

1. **采集**：右键点树 → 得木材；点岩石 → 得石头；点野外**浆果丛** → 得浆果（可当口粮）。资源进入**干活者自己的背包**，背包满则拒绝采集。
2. **种田**：`2` 播种模式，右键耕地 → 种下种子（从选中角色背包扣）；约 12 秒成熟变金黄，右键收获得食物。
3. **建造**：`3` / `4` 模式右键放置围栏与木屋（从选中角色背包扣木材/石头）；木屋附近休息可缓慢回血。
4. **战斗**：野狼会游荡并袭击落单的人；右键点狼进入战斗（互相掉血，倒地可复原）。击杀野狼，食物 +2 进击杀者背包。**夜晚野狼侦测更远、跑得更快、刷新更频繁。**
5. **贸易**：右键点游商帐篷打开贸易站——**卖食物 3 金/个、卖木材 1 金/个、卖石头 1 金/个、买种子 2 金/个、买木矛 8 金（攻击 +3，装备给选中角色）**。买卖作用于选中角色的背包。
6. **招募**：贸易站旁有流浪者，右键花费 **25 金** 招募入队（第 4 人空背包）；被招募后过一阵子会有新人来。
7. **昼夜**：约 4 分钟一个昼夜循环，光照/天色/雾色随之渐变，右上角显示时辰（清晨/正午/黄昏/夜晚/深夜）。
8. **生存**：角色会饿（`F` 从选中首位背包扣食物喂所有选中者，食物不够可吃浆果）、受伤（倒地后会自己爬起）；野狼会随时间刷新。
9. **背包**：每人独立背包（初始 木材3/石头2/食物3/种子1），容量 40 单位（木材/石头各占 2，食物/种子/浆果各占 1）；负重 ≥80% 移动减速 20%；选中面板可把物品转移给其他队员或丢弃。
10. **存档**：左上「存档」→ 自动槽（每 60 秒静默保存）+ 3 个手动槽；读档后建筑、农田生长、队员位置/血量/背包/木矛、金币、时辰全部恢复，树/岩石/浆果重置刷新，野狼重新生成；**导出 JSON / 导入 JSON** 可在浏览器间迁移进度。

**可复算的经济闭环**：1 金币买种子 → 收获 2 食物 → 卖出得 6 金币；采集物（木材/石头）也有 1 金/个的收购出口。所有数值集中在 `src/config.ts`。

## 项目结构

```
src/
  config.ts            # 全部数值/物品定义/色板/命名（as const 单一数据源）
  types.ts             # 领域类型：Tile / 实体 / Unit / 背包 / 存档
  state.ts             # 全局运行时状态 + 金币 + 存档待读标记
  main.ts              # 入口：组装世界、读档初始化、自动存档、主循环、调试钩子（?debug=1）
  core/
    renderer.ts        # 场景 / 相机 / 光照 / 画布挂载
    world.ts           # 地形分区、树木、岩石、浆果丛、流浪者、商人、农田格
    input.ts           # 键盘 / 鼠标 / 触摸输入
  entities/
    unit.ts            # 单位类（拓荒者与野狼共用，部位化身体 + 个人背包）
  systems/
    inventory.ts       # 背包：增删/容量/负重/转移（唯一入口）
    save.ts            # 存档：序列化/迁移/槽位/导出导入/自动存档
    daynight.ts        # 昼夜循环（光照/天色/时辰）
    farm.ts            # 播种 / 生长 / 收获
    build.ts           # 围栏 / 木屋（+读档纯放置）
    combat.ts          # 野狼 AI、战斗结算、刷新、资源重生
    economy.ts         # 进食 / 饥饿（扣选中首位背包）
    commands.ts        # 右键命令分发、拾取、交易触发、招募
  ui/
    hud.ts             # 资源栏 / 选中面板（含背包+转移）/ 日志 / 模式按钮 / 时辰
    tooltip.ts         # 悬停提示
    trade.ts           # 贸易面板（食物/木材/石头/种子/木矛）
    save.ts            # 存档菜单（槽位/导出/导入）
```

- **本轮全环节验证抓到并修复的真 bug**：采集升级后负重上限不即时生效（`refreshCapacity()` 前后端同步修）；防御保底 `max(1, dmg-def)` 会把饥饿持续伤害（0.1/tick）放大 10 倍（新增 pierce 真实伤害通道）；跑动经验浮点累加 100×0.1=9.9999… 永不达阈值（容差修复）。
- **S7 个体属性系统（spec 010，用就长）**：五维属性「体力/生命力/攻击/防御/饥饿度」全部由使用驱动成长——砍树练体力、挨咬练防御、命中练攻击、大难不死练生命力；体力是每天的干活预算（采集/跑动/攻击消耗，静止/进食恢复，告急减速）；饥饿联动（≤20 攻击 -1、采集变慢）；攻击 = 5 + 攻击属性 + 战斗技能 + 木矛；存档 v3→v4（旧档补默认属性，读档重算 maxHp/攻击）。

## Spec Kit（规格驱动开发）

本项目已接入 [GitHub Spec Kit](https://github.com/github/spec-kit)，采用 generic 集成。新功能开发走「需求 → 方案 → 任务 → 实现」的结构化流程：

| 命令 | 作用 |
| --- | --- |
| `/speckit.specify <功能描述>` | 写需求规格（WHAT/WHY，不写实现） |
| `/speckit.plan` | 基于 spec 出技术方案 |
| `/speckit.tasks` | 把方案拆成可执行任务列表 |
| `/speckit.implement` | 按任务列表写代码 |
| `/speckit.clarify` | 澄清规格中的模糊点 |
| `/speckit.analyze` | 校验 spec / plan / tasks 一致性 |
| `/speckit.converge` | 对照代码库，把剩余差距补成任务 |

- 每个功能的产物放在 `specs/NNN-功能名/` 下（`spec.md` / `plan.md` / `tasks.md`）。
- 项目治理原则见 `.specify/memory/constitution.md`。
- 命令模板在 `.specify/commands/`，核心模板在 `.specify/templates/`。

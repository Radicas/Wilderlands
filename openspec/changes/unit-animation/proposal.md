# Proposal

## Why

单位动画的地基已在 v0.2 落地（骨骼层级/走路摆腿/膝肘弯曲/身体起伏/采集挥臂），但玩家实际观感仍然"粗糙"：**转身瞬间闪现、站着完全冻结（无呼吸感）、倒地姿势硬切、尸体死后直立不倒、狼尾巴耳朵纹丝不动、砍树全程空手无工具**。角色是玩家盯着看 90% 时间的对象，这些断点直接暴露"纸片感"。手感抛光第一轮（gather-feedback）解决了"反馈"，这一轮解决"生命感"。

## What Changes

- **ADDED 转向平滑**：移动转向按 slerp 渐变（≈0.15s 完成），杜绝瞬间掉头
- **ADDED 待机微动画**：idle 时呼吸起伏 + 重心微移 + 头部偶发环视（低频），角色站着也是活的
- **ADDED 倒地/苏醒/死亡姿势**：倒地 0.3s 倾倒补间（替代硬切）、苏醒起立补间、死亡不再直立——尸体侧卧留在场景直至隐藏
- **ADDED 狼群细节动画**：奔跑摆尾、耳朵抖动（受击瞬间双耳后压一帧）、待机耳朵微转
- **ADDED 手持工具**：采集按资源类型持对应工具（斧/镐/篮），攻击持矛；工具挂在右手骨骼随挥砍联动；闲置时收背
- 摆动幅度类参数（walkSwing/bobHeight 等）作为可调数值随手感微调，不单列需求
- 纯表现层：不改任何游戏规则/结算/时序，**sim 无镜像义务**（163 断言作零波动哨兵）；存档 schema 不变（SAVE_VERSION 保持 5）

## Capabilities

### New Capabilities
- `unit-animation`: 单位生命感动画契约（转向/待机/倒地/死亡/狼细节/工具持握），含"动画不得影响行为时序"约束

### Modified Capabilities
- （无——现有规格未约束视觉动画；`combat-daynight` 的倒地恢复条款只定义逻辑恢复计时，姿势动画与其兼容）

## Impact

- **代码**：`src/entities/unit.ts`（`_updateAnimation` 扩展 + 倒地/死亡补间状态）、工具模型构建与骨骼挂点、`src/config.ts`（ANIM 块加 turnSpeed/breatheRate 等常量）
- **性能**：全量为既有骨骼补间加几组 sin/lerp，每帧成本可忽略；工具网格复用几何体共享材质
- **测试**：黑盒新增 `G22 动画生命感`（转向后 mesh 旋转角非瞬跳、idle 躯干 y 微动、倒地 0.35s 后 rotation.x 接近 90°、工具节点存在性）；sim-run 豁免（同 gather-feedback：纯表现层）
- **依赖**：无阻塞；与在途 death-system/medical-limbs 正交（它们改何时倒地，本 change 改倒地看起来如何）

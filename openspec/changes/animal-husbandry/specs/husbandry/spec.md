# Spec Delta

## Purpose

定义荒野定居的最后一环：围栏内驯养动物的成活、产出与警戒行为契约——鸡供蛋的稳定食线、狼崽看家的伙伴关系，以及它们同样会死于野狼袭击的风险闭环。

## ADDED Requirements

### Requirement: 驯养成活
在围栏区域内对动物持续投喂（鸡用食物、狼崽用浆果/肉）SHALL 使其从幼体成长为成年；未圈进围栏的动物 MUST 不接受驯养且可能逃逸。投喂中断时成长倒计时暂停而非清零。

#### Scenario: 喂熟一只鸡
- **WHEN** 围栏内的幼鸡被按节奏投喂达到成长需求
- **THEN** 该鸡进入成年态并在面板/日志可辨认

### Requirement: 周期性产出
成年鸡 SHALL 按游戏时间周期下蛋，蛋作为新食物物品进入可拾取/可交易/可食用路径；产出 MUST 受农场类技能或饲养状态的正向影响，且夜袭等中断不会凭空复制产出。

#### Scenario: 捡蛋
- **WHEN** 成年鸡完成一个产蛋周期
- **THEN** 围栏内出现可拾取的蛋，拾取后食物计数增加且不会二次出现

### Requirement: 看门狼警戒与保卫
驯成的看门狼 SHALL 在敌狼进入警戒半径时发出预警日志并主动迎战；对玩家命令体系 MUST 保持可指挥（与队员同样接受攻击令且性格让位）。看门狼被咬伤走同一倒地规则，生命归零按 animal-husbandry 的风险结算死亡（不套用角色墓碑/传承）。

#### Scenario: 夜狼来袭先吠
- **WHEN** 一只野狼在夜间接近驯养区且看门狼清醒在岗
- **THEN** 日志出现预警，看门狼迎击；玩家下令时看门狼可被指挥

# Proposal

## Why

当前角色生命归零只会"倒地→自动苏醒"，战场没有真正的风险与代价，死亡完全没有重量。S8 死亡体系（原路线图 spec 011 编号已过时，按行为重新立项）要建立"倒地是最后的机会、死亡有后果"：救援窗口、扛人、阵亡散落与墓碑、遗志传承；主角例外回家，保住沙盒可玩性。

## What Changes

- 倒地新增**救援窗口**：窗口内可被队友扶起（加速苏醒）或玩家拖拽搬运；窗口耗尽无人救援才进入死亡结算。
- **阵亡后果**：物品散落在倒下处、原地立墓碑（可读名字）、日志宣告。
- **遗志传承**：阵亡者的命名传承给下一名招募队员（荒诞感），其个人日志条目留下纪念。
- **主角例外**：第一名拓荒者（罗恩）永不真正死亡——重伤时被自动抬回木屋/商摊苏醒，代价是掉落部分随身物品。
- 倒地态在**窗口内**保持现有"不可选中下令"的边界，但增加可被救援交互。

## Capabilities

### New Capabilities
- `death-legacy`: 死亡结算、散落、墓碑、遗志传承与主角重伤回家的行为契约。

### Modified Capabilities
- `combat-daynight`: "倒地与苏醒"需求改为"倒地→救援窗口→（获救苏醒 | 窗口耗尽阵亡）"三分支，替换现有纯自动苏醒。

## Impact

- `entities/unit.ts` 倒地状态机 + 救援交互；`systems/combat.ts` 伤害归零路径；`core/input.ts`/`commands.ts` 扶起/扛人命令；新增 `systems/death.ts`（纯逻辑，sim 可共用）；墓碑作为世界实体入 `worldgen/build` 注册路径。
- 存档 schema 需要扩展（墓碑/传承/散落地）→ 预期 v5→v6 迁移，migrate.ts 补链。
- 平衡数值（窗口秒数、掉落比例、抬回速度）进 config 单一来源。

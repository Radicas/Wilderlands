# Spec Delta

## MODIFIED Requirements

### Requirement: 倒地与苏醒
玩家角色生命归零 MUST NOT 直接死亡，而是进入倒地态：停止一切任务与移动、不可被选为命令主体。倒地 SHALL 开启限时救援窗口——窗口内任一队友抵达执行扶起/拖拽可让其提前苏醒并保留部分生命；窗口自然结束时，普通队员进入阵亡结算、主角触发重伤回家例外。自动苏醒的保底生命与生命力经验规则保持（苏醒者获得"大难不死"成长）。

#### Scenario: 获扶提前苏醒
- **WHEN** 一名队友被下令前往倒地队员处并完成扶起交互
- **THEN** 倒地队员在窗口内苏醒，两者都可再次行动

#### Scenario: 倒地后自动苏醒
- **WHEN** 倒地角色在救援窗口内被队友扶起交互
- **THEN** 角色提前苏醒，生命值不低于保底值、日志出现"苏醒"并累积生命力经验

#### Scenario: 窗口内无人则按身份分支
- **WHEN** 救援窗口耗尽时普通队员与主角各自倒地到底
- **THEN** 普通队员阵亡结算，主角重伤回家

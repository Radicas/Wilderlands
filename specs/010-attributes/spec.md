# spec 010 · 个体属性系统（用就长）

> 阶段目标：把「体力 / 生命力 / 攻击 / 防御 / 饥饿度」做成**用就长**的属性成长底座。
> 技能（gather/combat/farm/medic）管**效率**，属性管**底子**，二者都由使用驱动成长。
> 死亡系统（spec 011）、医疗肢体系（spec 012）都建立在属性之上。

## 1. 五属性定义

| 属性 | 含义 | 基础值 | 升级效果 | 经验来源（用就长） |
|---|---|---|---|---|
| 体力 stamina | 每天的干活预算 | 100 | +10/级，封顶 150 | 砍树/凿石/浆果/种地/跑动/攻击 |
| 生命力 vitality | 生命上限 | 100 | +5/级，封顶 150 | 被治疗、倒地爬起 |
| 攻击 atk | 基础攻击 | 5 | +1/级 | 攻击命中狼、击杀 |
| 防御 def | 减伤 | 0 | +1/级（减伤 1/级） | 被狼咬 |
| 饥饿度 hunger | 消耗性资源，不升级 | 100 | — | 维持生存（已有机制） |

属性等级与经验表：**复用 `CFG.skillXPForLevel`（3,8,15,25,40）**，Lv0 起，封顶 Lv5。

## 2. 规则

### 2.1 攻击与防御

- `atkDmg = CFG.atkDmg(5) + atkLv + 战斗技能加成(atkBonus) + 木矛(3)`
  - 注：属性与技能叠加，但封顶自然收敛（5+5+4+3=17），狼 hp30 → 2 刀。
- 受击伤害：`max(1, 狼伤3 - defLv)` —— 防御 0 级不变、Lv1 减 1、Lv3+ 保底 1。

### 2.2 体力预算

| 动作 | 消耗 |
|---|---|
| 砍树 / 凿石 / 采浆果 | -3 / 次 |
| 种地（翻土） | -2 / 次 |
| 攻击 | -2 / 次 |
| 跑动 | -0.5 / 秒 |

- 恢复：静止 +1/秒；**进食 +30 体力**（与回血同时生效）。
- 惩罚：体力 ≤ 20% → 移动速度 ×0.8、采集工作速度 ×0.8。
  - 文案：「罗恩累得砍不动了，树在旁边笑他。」

### 2.3 饥饿联动（荒诞）

- 饥饿 ≤ 20 → 攻击 -1、采集工作速度 ×0.9。
  - 文案：「罗恩饿得把斧头看成了鸡腿。」

### 2.4 经验来源（与既有动作挂钩，不新增操作）

| 事件 | 属性经验 |
|---|---|
| 砍树/凿石/采浆果/种地/跑动 ≥1 秒/攻击 | 体力 +1（每动作一次） |
| 被治疗恢复 | 生命力 +1 |
| 倒地爬起（含主角重伤回家） | 生命力 +1 |
| 攻击命中狼 | 攻击 +1 |
| 被狼咬伤 | 防御 +1 |

## 3. 存档 v4

- `SAVE_VERSION 3 → 4`。
- `units[i]` 增加 `attrs: { stamina, staminaXp, vitalityXp, atkXp, defXp }`。
  - 等级全部从 xp 推导（`attrLevel(xp)`），不存等级。
  - 旧档迁移：补 `{ stamina:100, staminaXp:0, vitalityXp:0, atkXp:0, defXp:0 }`。
- 读档恢复：`maxHp = 100 + vitalityLv*5`、`atkDmg = 5 + atkLv + atkBonus + (hasSpear?3:0)`、防御等级用于受击判定。

## 4. sim 断言清单（scene: 属性系统）

1. 砍树 3 次 → stamina 91、staminaXp 3 → Lv1 → 上限 110
2. 跑动 10 秒 → stamina -5；静止 5 秒 → +5
3. 进食 → stamina +30 且 hp 同时 +50（双收益）
4. 体力 ≤20% → 移动速度 ×0.8（同距离耗时更长）
5. 挨咬 5 次 → defXp 5 → Lv1 → 狼伤 3→2
6. 命中狼 → atkXp +1 → Lv1 → atkDmg +1
7. 饥饿 ≤20 → 攻击 -1、采集变慢
8. 存档 v4：attrs 字段往返 + 旧档迁移补默认 + 读档 maxHp/atkDmg 重算

## 5. 规则对照（防漂移，前端必须照守）

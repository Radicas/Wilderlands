# Feature Specification: 选中交互与采集优化

**Feature Branch**: `002-selection-gathering`

**Created**: 2026-10-22

**Status**: Draft

**Input**: User description: "1. 初始角色选中后再移动，大小发生了变化，大小不希望变化。2. 选中人物砍树、凿石头，获取素材后树和石头没有消失。一棵树和一个石头应该有固定的产出量，产出后就要消失。3. 没有框选编队的功能。希望能类似红色警戒一样，可以选中，一起行动。一起选中后，如果进行工作交互，那么他们要有碰撞，围绕着目标"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 选中视觉反馈不改变模型外观 (Priority: P1)

玩家左键选中角色时，模型本身的颜色、大小、形状完全不变，只有头顶的金色菱形标记亮起表示选中状态。

**Why this priority**: 这是最直观的视觉 bug，用户第一眼就注意到了。

**Independent Test**: 左键点击任一角色，观察模型本身没有任何外观变化，只有头顶标记亮起；取消选中后标记消失。

**Acceptance Scenarios**:

1. **Given** 游戏已启动，3 名拓荒者站在出生点，**When** 左键点击选中其中一名，**Then** 该角色的模型颜色、大小、形状完全不变，只有头顶金色标记亮起。
2. **Given** 已选中一名角色，**When** 再次点击取消选中，**Then** 头顶标记消失，模型外观恢复正常。

---

### User Story 2 - 采集产出后实体消失 (Priority: P2)

玩家派角色砍树或凿石头，当树/石头的总产出量被采完后，该实体立即从世界中消失，过一段时间重新刷新。

**Why this priority**: 采集是核心玩法，树/石头不消失会导致资源无限刷，破坏经济平衡。

**Independent Test**: 派角色砍树，砍完一次后树消失；派角色凿石头，凿完指定次数后石头消失。

**Acceptance Scenarios**:

1. **Given** 一棵活着的树，**When** 派角色砍树（一次采集完成），**Then** 树立即从世界中消失，木材数量增加，过一段时间树在原地重新长出来。
2. **Given** 一块活着的石头（有耐久度），**When** 派角色凿石头直到耐久度耗尽，**Then** 石头立即从世界中消失，石头数量增加，过一段时间石头在原地重新出现。
3. **Given** 多个角色被派去采同一个资源，**When** 资源总产出量耗尽，**Then** 资源立即消失，所有正在采集的角色自动停止并返回空闲状态。

---

### User Story 3 - 鼠标拖拽框选编队 (Priority: P3)

玩家按住左键拖拽出一个矩形框，框内的所有拓荒者被同时选中。右键下达移动命令时，所有选中角色一起移动并保持相对位置。右键下达采集/攻击命令时，多个角色自动围绕目标站位，不会重叠挤在一起。

**Why this priority**: 这是从"单角色操作"到"小队操作"的核心体验飞跃，类似红警的框选编队。

**Independent Test**: 鼠标拖框选中多个角色，右键移动时他们一起走，右键砍树时他们围绕树站成一圈。

**Acceptance Scenarios**:

1. **Given** 游戏已启动，**When** 按住左键拖拽出一个矩形框松开，**Then** 框内的所有拓荒者被同时选中，头顶都亮起金色标记。
2. **Given** 多名角色被选中，**When** 右键点击地面下达移动命令，**Then** 所有选中角色一起移动到目标点附近，彼此保持合理间距，不会重叠。
3. **Given** 多名角色被选中，**When** 右键点击一棵树下达砍树命令，**Then** 所有角色自动分散站在树的周围（而不是全部挤在树的同一个点），同时开始砍树。
4. **Given** 多名角色被选中，**When** 右键点击一只野狼下达攻击命令，**Then** 角色们从不同方向靠近野狼，不会全部挤在同一个位置。

---

### Edge Cases

- 框选时如果只拖了一个很小的矩形（误操作），不应该选中任何角色。
- 框选时 Shift 键的行为：按住 Shift 框选应该是追加选中，而不是替换。
- 采集时多个角色同时到达目标，他们的站位需要自动分配，不能重叠。
- 资源消失时正在采集的角色应该怎么处理：自动停止还是继续？

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 选中角色时，模型的颜色、大小、形状 MUST 完全不变，只有头顶金色标记亮起作为唯一选中反馈。
- **FR-002**: 砍树一次后，树 MUST 立即从世界中消失（visible = false），过一段时间重新刷新。
- **FR-003**: 石头的耐久度耗尽后，石头 MUST 立即从世界中消失，过一段时间重新刷新。
- **FR-004**: 玩家 MUST 能通过鼠标拖拽矩形框选中多个角色（类似红色警戒的框选）。
- **FR-005**: 框选 MUST 只选中拓荒者（player），不选中野狼。
- **FR-006**: 多个角色一起移动时，MUST 保持相对间距，不能重叠在同一个位置。
- **FR-007**: 多个角色采集同一个目标时，MUST 自动分散站位在目标周围，而不是全部挤在同一个点。
- **FR-008**: 框选时按住 Shift MUST 是追加选中模式（保留已选中的角色），不按 Shift 是替换选中。

### Key Entities

- **选中状态**: 从"改模型颜色"改为"仅头顶标记"，模型外观完全不变。
- **资源实体消失**: 树/石头产出耗尽后立即隐藏，respawn 计时结束后重新显示。
- **框选系统**: 鼠标左键拖拽时在屏幕上绘制半透明矩形，松开时计算矩形覆盖范围内的所有拓荒者。
- **小队移动**: 右键移动时，每个选中角色的目标点在目标位置周围随机偏移，避免重叠。
- **围绕站位**: 采集/攻击时，每个角色的工作位置在目标周围按角度均匀分布。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 选中角色时模型外观完全不变，只有头顶标记变化。
- **SC-002**: 树砍一次就消失，石头凿完耐久就消失，不再出现"采了还在"的情况。
- **SC-003**: 鼠标拖框能一次性选中多个角色，体验类似红色警戒。
- **SC-004**: 多名角色一起移动或工作时，彼此保持至少 0.8 米间距，不会重叠。
- **SC-005**: 现有单角色操作逻辑完全不变（不框选、只选一个人的体验和之前一样）。

## Assumptions

- 框选用鼠标左键拖拽实现，不引入快捷键。
- 小队移动时的站位偏移用简单的随机角度+半径分配，不做复杂的避障寻路。
- 围绕目标工作时的站位按"每个角色一个角度"均匀分布，最多支持 6-8 个角色同时采同一个目标。
- 不做单位碰撞体积物理系统，只通过目标点偏移来避免视觉重叠。

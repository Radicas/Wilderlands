# Feature Specification: 视觉精细化升级

**Feature Branch**: `001-visual-polish`

**Created**: 2026-10-22

**Status**: Draft

**Input**: User description: "角色和动物、地形还是不够精细。我希望更精细一点"（已澄清：保持低多边形风格，方向为模型几何圆润化 + 地形起伏 + 动作动画生动，不做材质纹理升级）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 角色与野狼造型更自然 (Priority: P1)

玩家打开游戏，第一眼看到的拓荒者不再是生硬的方块人，野狼也不再是方盒子拼的。模型轮廓圆润、有四肢分段和自然比例，但仍然一眼能看出是 low-poly 风格，不是写实风。

**Why this priority**: 角色是玩家全程盯着看的主体，模型造型是"精细不精细"最直观的感受。P1 是因为它是核心观感。

**Independent Test**: 进入游戏后，镜头拉近看任一拓荒者和一只野狼，能分辨出头、躯干、四肢的分段，形状不再是纯方块；整体仍是低多边形、面数低，性能无明显下降。

**Acceptance Scenarios**:

1. **Given** 游戏已启动，3 名拓荒者站在出生点，**When** 镜头拉近到 3 米内观察，**Then** 能看到头部是球体/胶囊体、躯干有收腰、四肢是分段圆柱（上臂+下臂、大腿+小腿），而非一整块方块。
2. **Given** 一只野狼在野外游荡，**When** 靠近观察，**Then** 能看到狼的身体是拉长的椭球、有四条腿、尾巴自然下垂，头部有口鼻轮廓，而不是方盒子加耳朵。
3. **Given** 升级前后对比，**When** 观察同屏同数量的角色和动物，**Then** 帧率不下降超过 5%（仍保持 low-poly 风格，不引入高面数模型）。

---

### User Story 2 - 地形有自然起伏 (Priority: P2)

地面不再是平瓷砖铺成的棋盘，而是有缓坡、小丘和洼地。树木、岩石、建筑、农田都落在起伏后的地面上，不会出现悬浮或穿模。

**Why this priority**: 地形起伏是"荒野感"的主要来源，平地板的感觉会让场景像个沙盘。但它不像角色那样时刻被盯着，所以 P2。

**Independent Test**: 移动镜头扫过整个游戏区域，能看到地面有高低差，远处和近处不在同一水平面上；所有实体（人、树、岩石、农田、建筑）都稳稳落在地面上。

**Acceptance Scenarios**:

1. **Given** 游戏世界已生成，**When** 沿地面走一圈，**Then** 地面有 ±0.5 到 ±1.5 米的自然起伏，不是完全平的；起伏是缓坡而非悬崖。
2. **Given** 起伏地形生成后，**When** 检查树木、岩石、角色、建筑的 Y 坐标，**Then** 它们的底部都贴合所在位置的地面高度，没有悬浮或陷入地下。
3. **Given** 农田系统，**When** 在起伏地形上播种/收获，**Then** 农田地块的高度跟随所在地形高度，操作仍正常。

---

### User Story 3 - 动作动画更生动 (Priority: P3)

角色走路时四肢有自然摆动、身体上下轻微起伏；砍树/挖矿时有明显的挥砍动作；野狼移动时有跑动姿态。而不是现在这样直挺挺地平移、只有躯干转一下。

**Why this priority**: 动画是"活起来"的感觉，但它依赖模型先有可动的四肢分段。所以排在模型造型之后。

**Independent Test**: 给角色下达移动命令，观察走路时手臂和腿有前后摆动；下达砍树命令时能看到挥工具的动作；野狼跑动时四肢有交替姿态。

**Acceptance Scenarios**:

1. **Given** 一名拓荒者接到移动命令走向远处，**When** 观察走路过程，**Then** 左右腿交替前后摆动、手臂自然摆动、身体随步伐有轻微上下起伏，不是整块平移。
2. **Given** 拓荒者开始砍树，**When** 观察采集动作，**Then** 有明显的挥工具过头顶再落下的循环动作，而不是躯干微微转一下。
3. **Given** 野狼向玩家冲来，**When** 观察野狼移动，**Then** 四肢有跑动姿态，身体有轻微起伏，而不是方盒子滑过去。

---

### Edge Cases

- 地形起伏后，相机边界和阴影范围是否需要调整，避免出现阴影边缘断层。
- 角色倒地（rotation.x = π/2）时，新的四肢分段模型会不会出现奇怪的穿插。
- 低多边形风格约束下，动画幅度不能太大，否则会显得卡通化过重。
- 性能约束：同屏角色（3人 + 最多6只狼）+ 46棵树 + 22块岩石，升级后不能掉帧。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 拓荒者模型 MUST 由分段几何体组成，至少包含：头部（球体或圆角立方体）、躯干（带收腰的柱体）、左右上臂+下臂、左右大腿+小腿，而非单一方块堆叠。
- **FR-002**: 野狼模型 MUST 由更自然的几何体组成：拉长的身体椭球、头部带口鼻轮廓、四条分段腿、自然下垂的尾巴、竖立的耳朵。
- **FR-003**: 所有角色和动物的新模型 MUST 保持低多边形面数（单个模型总面数不超过 ~200 三角面），不引入高面数建模。
- **FR-004**: 地形 MUST 从完全平坦改为有自然起伏的缓坡地形，起伏幅度控制在 ±0.5 到 ±1.5 米之间，使用噪声函数生成，不能是随机尖刺。
- **FR-005**: 地形上的所有实体（树木、岩石、建筑、农田、角色）MUST 自动贴合所在位置的地面高度，不能悬浮或穿模。
- **FR-006**: 拓荒者移动时 MUST 有行走动画：左右腿交替摆动、手臂反相摆动、身体随步伐轻微上下起伏。
- **FR-007**: 拓荒者采集（砍树/挖矿）时 MUST 有挥砍循环动画，工具举过头顶再落下，而非当前的躯干小幅旋转。
- **FR-008**: 野狼移动时 MUST 有四足跑动姿态：四肢交替、身体轻微起伏。
- **FR-009**: 所有新模型和动画 MUST 不引入外部资源文件（不加载 .glb/.gltf/贴图），全部用 Three.js 基础几何体程序化生成。
- **FR-010**: 升级后 `tsc --noEmit` MUST 保持 0 错误，`vite build` MUST 通过，同屏帧率下降不超过 5%。

### Key Entities

- **造型化角色模型**: 由多个基础几何体组合而成的 Group，包含可动画的四肢引用（左右上臂、左右下臂、左右大腿、左右小腿、头部）。
- **起伏地形网格**: 由 PlaneGeometry 或细分 BoxGeometry 组成的地面，每个顶点的 Y 值由噪声函数计算。
- **动画状态**: 每个单位持有当前动画类型（idle / walk / gather / attack）和动画进度时间，主循环驱动。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 角色和动物模型不再由纯 BoxGeometry 堆叠组成，肉眼可分辨出自然轮廓和四肢分段，同时仍保持 low-poly 风格。
- **SC-002**: 地面不再是完全平坦的棋盘格，移动镜头能看到缓坡起伏，所有实体底部贴合地面。
- **SC-003**: 走路、采集、野狼跑动时能观察到明显的循环动作动画，而非整块平移或躯干微转。
- **SC-004**: 同屏满载时（3人 + 6狼 + 46树 + 22岩石），帧率与升级前相比下降不超过 5%。
- **SC-005**: 游戏可玩性不受影响——采集、种田、建造、战斗、贸易的操作方式和数值闭环完全不变。

## Assumptions

- 保持现有 low-poly 美术风格，不引入写实渲染、PBR 材质或外部 3D 模型资源。
- 不做材质纹理升级（用户已明确排除），仍然用纯色 MeshLambertMaterial。
- 现有玩法逻辑（采集、种田、战斗、经济）完全不变，只改视觉表现层。
- 地形起伏是缓坡，不影响现有格子化农田的交互逻辑（农田仍按格子交互，只是地块高度跟随地形）。
- 动画用程序化关键帧（sin/cos 驱动骨骼旋转），不引入动画系统库。

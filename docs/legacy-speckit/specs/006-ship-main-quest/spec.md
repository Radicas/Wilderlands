# v0.4 · 主线目标：修船通关（S4）规格

> 版本：v0.4 · 状态：已实现并回归（2026-10-22）
> 定位：六关键词「沙盒·种田·养殖·生存·荒诞·团队管理」——S4 落地「荒诞」主线：一艘倒扣在荒野中央的破船，没人见过海，可它就是搁浅在这儿了。

## 1. 目标

给游戏一个可完成的主线目标：找到荒野深处的破船 → 投入木材/石头修复 → 材料集齐触发「通关」（船翻正 + 穿水手服的狼船长登场 + 通关横幅）→ 进入自由模式继续玩。修船进度随存档持久化（存档 v2→v3 迁移）。

## 2. 数值（`src/config.ts` 单一数值源）

| 项 | 值 | 说明 |
| --- | --- | --- |
| `shipPos` | x:36, z:36 | 船的世界坐标（野外深处，家园区外） |
| `shipWoodNeed` | 30 | 修船木材总需求 |
| `shipStoneNeed` | 20 | 修船石头总需求 |
| `shipDonateWood` | 10 | 每次投入木材量 |
| `shipDonateStone` | 5 | 每次投入石头量 |
| `shipNearDist` | 8 | 距船 ≤8 才能投入材料 |

- 完成判定（纯函数）：`wood≥30 && stone≥20`。
- 投入封顶：`min(need, cur+amount)`，不会超投。
- 完成后拒绝继续投入。

## 3. 世界与视觉（`src/entities/ship.ts`）

- `buildShip()`：在 (36,36) 建倒扣破船组——横躺船体 + 倒扣船底壳 + 竖直桅杆 + 破旧斜帆 + 船首小木狼头彩蛋；注册交互 `kind:'ship'`。
- 翻正动画：`updateShip(dt)` 驱动 `group.rotation.x` 0→π 平滑翻转，完成后换新帆。
- `spawnCaptain()`：狼船长——野狼配色箱体 + 蓝色水手帽 + 红领巾 + 尾巴，位于船旁，面向船，带轻微呼吸浮动；交互 `kind:'captain'`（右键荒诞对话）。
- 读档 `ship.done=true`：直接翻正 + 船长在场（无动画）。

## 4. 玩法接线

- 右键船（`commands.ts` kind:'ship'）：选中小队走到船边（新任务类型 `walk`）+ 打开修船面板。
- 修船面板（`ui/ship.ts`）：荒诞文案 + 材料进度 + 两个投入按钮。
  - 投入校验顺序：已完成？→ 选中队员距船 ≤8？→ 背包材料足够？（`invRemove` 扣料）→ `donateToShip` 推进 → 集齐则 `finishShipVisual()` + 通关横幅。
- 通关横幅（index.html `#victory`）："主线达成·船修好了" + 荒诞文案 + 自由模式提示，8 秒后自动消失。
- 右键狼船长：三句随机荒诞台词（logMsg）。
- tooltip：船 = "搁浅的破船 · 主线目标（右键修船）"；船长 = "船长 · 一头穿水手服的野狼（右键聊聊）"。
- debug 面板：`船 wood/30 石 stone/20`，完成后追加"已修好"。

## 5. 存档（v2 → v3 迁移）

- `SaveData` 增 `ship: { wood, stone, done }`，`version: 3`。
- `migrateSave`：v2→v3 补默认船（0/0/false）；v1 经 v2 链式到 v3；v3 透传。不合法（缺 units 等）拒绝。
- `collectSave` 写 ship；`applySave` 恢复 ship（`??0` 兜底）。
- 船不存档临时态（动画/船长引用），只存档进度；船位置世界内固定，无需坐标。

## 6. 回归与验证

- `scripts/regress.sh` 七步：tsc → vite build → 产物断言 → 迁移 15 项 → 技能 24 项 → 价格 17 项 → **修船 9 项**。
- `scripts/ship-check.mjs`（9 用例）：完成阈值（未集齐/刚集齐/超出）、投入封顶、完成后拒绝。
- 实机（dev/preview `?debug=1`）：注入 v3 存档（罗恩 wood40/stone20 于船边）→ 选中罗恩 → 连续投入木材×3 石头×4 → 扣背包（40→10、20→0）、进度 30/30 20/20 → 日志"咣当！破船翻正了" + 通关横幅（荒诞文案）→ debug"船 30/30 石20/20 已修好" → 存档落盘 `ship:{wood:30,stone:20,done:true}` → 读档恢复翻正船 + 狼船长（蓝水手帽）。
- 环境限制缺口：窄屏（235×848）下 canvas 右键命中不稳定，右键船弹面板/右键船长对话为间接验证（hover tooltip 命中同一 raycast 路径 + 面板按钮链实机通过）；代码路径简单、无状态分支。

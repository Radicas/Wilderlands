# spec 011 · 角色 AI（性格 + 情绪 + 闲时自治）

> 阶段目标：把拓荒者从"等命令的模型"变成"有脾气的队友"。
> 核心原则：**玩家永远是主角**，性格只在玩家没下命令时生效；玩家一下令，全员执行。
> 性格靠玩家观察发现，**不做性格面板**。

## 1. 性格系统

每个角色开局从三个维度各抽一个，组合决定他的行为倾向。流浪者招募时也随机抽。

### 1.1 战斗维度（4 选 1）

| 性格 | 看到狼（玩家未下攻击命令时） |
|---|---|
| `aggressive` 莽夫 | 主动迎上去打，不管自己血多少 |
| `cautious` 谨慎 | 先后退 2 步，玩家上了他才上 |
| `timid` 胆小 | 转头跑向最近的队友/商摊，狼走远才回来 |
| `stoic` 老兵 | 不慌不忙迎上，血 <30% 时自己撤 |

### 1.2 工作维度（4 选 1）

| 性格 | 闲下来（无任务）时倾向 |
|---|---|
| `hardworking` 勤劳 | 10 米内有啥干啥（树→石→浆果，按距离） |
| `lazy` 懒惰 | 站着发呆，不主动找活 |
| `gatherer` 采集者 | 10 米内优先找浆果，其次才砍树挖矿 |
| `woodsman` 伐木工 | 10 米内优先砍树，其次才别的 |

### 1.3 性格维度（4 选 1）

| 性格 | 平时表现 |
|---|---|
| `talkative` 话痨 | 干活/遇狼/天黑时偶尔吐槽（日志） |
| `quiet` 沉默 | 几乎不说话 |
| `glutton` 吃货 | 背包有浆果且饥饿 <60 时自己啃；饿了会喊 |
| `tough` 坚韧 | 饿/受伤不吭声，血条红了也不提醒 |

### 1.4 规则

- 三个维度独立随机，互不冲突（64 种组合）。
- **玩家手动下命令时（右键点树/狼/地面），性格完全靠边**：全员按命令执行，哪怕他是胆小的也会冲上去打狼。打完后性格恢复。
- 性格不显示在 UI 上。玩家通过行为和日志自己发现。
- 新角色（开局 3 人 + 流浪者）随机分配，不允许重随。

## 2. 情绪系统

情绪是临时状态，自动来自动走，不做面板。玩家通过行为变化和日志感知。

| 情绪 | 触发条件 | 行为影响 | 消退条件 |
|---|---|---|---|
| `fear` 害怕 | 被狼咬过、看到队友倒地、夜晚独自一人（离商摊 >15 米） | 干活速度 ×0.8、狼来了更容易跑 | 回到商摊 15 米内 / 天亮 / 队友在身边 |
| `irritable` 烦躁 | 饥饿 ≤20 | 干活速度 ×0.9、偶尔吐槽 | 吃东西后消退 |
| `exhausted` 疲惫 | 体力 ≤20 | 移动速度 ×0.9 | 静止 10 秒后消退 |
| `downcast` 低落 | 看到队友倒地 | 不说话（压过话痨属性） | 30 秒后自然消退 |

- 情绪可以叠加，但行为惩罚不叠加（取最差的那个倍率）。
- 情绪状态不存数字，只存当前情绪标签（最多 1 个，新情绪覆盖旧情绪）。
- 日志只在情绪变化时冒一句，不刷屏。

## 3. 闲时自治

- 角色没有任务（`task === null`）且不是倒地/死亡时，进入"闲时模式"。
- 闲时行为范围：以**当前选中的领队（selected[0]）为中心 10 米内**。
- 按工作性格找活：
  - 找到活 → 自动派一个 gather 任务过去（和玩家右键派的任务结构一样）。
  - 没找到活 → 站着等。
- **背包满了自动停**（invRatio ≥ 1 时不找活）。
- 玩家一下令（任何 commandAt），所有闲时任务立即取消，全员听指挥。
- 懒惰型不进入闲时找活，纯发呆。

## 4. UI 改造

点角色后左侧面板拆成上下两块：

### 4.1 上窗口（状态）
- 名字
- 血条 / 饥饿条 / 体力条（现有）
- 四肢状态（现有）
- 技能等级（现有）
- **新增：当前行为**（"正在砍树""害怕中""发呆""扛着 XX"——从任务/情绪推导）
- **不显示性格标签**

### 4.2 下窗口（背包）
- 现有背包列表 + 转移按钮，不变。
- 不做 tab 切换，不做"工作安排"页。

## 5. 不做什么（本 spec 范围外）

- 倒地救援、扛人、医疗房、医疗道具 → 等建造/物品系统
- 性格编辑器、性格面板、重随按钮
- 好感度、队友关系网
- 情绪面板、心情数字
- 多人联机

## 6. 存档兼容

- `SAVE_VERSION 4 → 5`。
- `units[i]` 增加：
  - `personality: { combat: string, work: string, trait: string }`
  - `mood: string`（当前情绪标签，默认 `'neutral'`）
- 旧档迁移：随机补一套性格，mood 默认 `'neutral'`。
- 读档不恢复性格（每次读档重随性格也可以——但更好的是存住，避免同一人读档后变了个人）。**存住。**

## 7. sim 断言清单

1. 开局 3 人各有一套三属性性格，且组合合法
2. 莽夫在玩家未下命令时看到狼会主动迎上
3. 胆小在玩家未下命令时看到狼会跑开
4. 玩家右键点狼后，胆小也会冲上去打
5. 勤劳型闲时 10 米内有树会自己过去砍
6. 懒惰型闲时不动
7. 被狼咬后 mood = fear，干活变慢
8. 吃东西后 mood 从 irritable 恢复
9. 玩家下命令后所有闲时任务取消
10. 存档 v5：personality + mood 往返 + 旧档迁移

## 8. 规则对照

- 性格/情绪常量（10 米范围、速度倍率、消退时间）唯一来源：`src/config.ts`。
- 性格随机与行为判定：新文件 `src/systems/personality.ts`（纯逻辑，无 three 依赖，可进 sim）。
- 前端同步点：`entities/unit.ts`（闲时找活、情绪影响速度、狼来了反应）、`ui/hud.ts`（上窗口当前行为）、`systems/save.ts` + `migrate.ts`（v5）。
- 不违反宪法 III（分层）：personality 逻辑进 systems/，渲染只看 unit 的当前行为标签。

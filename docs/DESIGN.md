# Wilderlands · 游戏设计文档（GDD v0.1）

## 1. 概念

**一句话**：在低多边形的荒野上，带领三人拓荒小队采集、种田、建造、战斗、贸易，从一穷二白到站稳脚跟的沙盒生存游戏。

**设计母题**（缝合自用户的期望组合）：

| 母题 | 来源 | 在本作中的体现 |
| --- | --- | --- |
| 高自由度沙盒 | Kenshi / RimWorld 风 | 右键语境命令：点哪干哪，无任务线 |
| 种田 | 星露谷 / 牧场物语 | 播种 → 生长 → 收获的经济正循环 |
| 探索 | 开放世界 | 地形三区分区，野狼与资源分布 |
| 生存 | Don't Starve 风 | 饥饿、受伤、倒地恢复 |

**体验目标**：前 10 分钟即进入「采集 → 种田 → 交易」的正反馈环；单位是可感知的个体（部位受伤、倒地、饥饿），而不是无脑棋子。

## 2. 核心循环

```
采集(树/岩) → 建据点(围栏/木屋) → 种田(买种子→种→收)
        ↑                              ↓
    防御野狼 ←—— 卖出食物换金币 ——→ 扩大再生产
```

单次经济闭环（可复算）：`买种子 2 金 → 收获 2 食物 → 卖出 6 金`。玩家必须循环：种子产出食物、食物换金币、金币买种子与建材。

## 3. 数值设计（`src/config.ts` 为唯一数据源）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 起始金币 / 木材 / 石头 / 食物 / 种子 | 20 / 10 / 5 / 10 / 5 | 保证开局 3 分钟内有东西可做 |
| 食物卖出价 / 种子买入价 | 3 金 / 2 金 | 单循环利润率 200%，节奏紧凑 |
| 农田生长时间 | 12 秒 | 一次收获 ≈ 一轮聊天的时间 |
| 单位速度 | 0.04（世界单位/帧） | 与地图尺寸（40×40）匹配 |
| 部位血量 | 头/躯干/双臂/双腿各 100 | Kenshi 式部位化，为后续残疾系统留接口 |
| 饥饿速率 | 每秒 -0.025 | 从 100 饿到 0 约 67 分钟（长局友好） |
| 野狼刷新 | 上限 8 只，3 秒内最多 2 只 | 保证压力但不淹没玩家 |

## 4. 系统设计

### 4.1 世界（`core/world.ts`）
- 40×40 世界，`PlaneGeometry` 地面 + 2×2 农田格（BoxGeometry 20×20 格）。
- **地形三区分区**（用户反馈「画面分不清」后的核心视觉决策）：
  - 内圈（距原点 < 8）：草绿 `#5a7a48` 家园区，出生与据点；
  - 中圈（< 18）：黄褐 `#6a5a3a` 野地，树木与岩石密集；
  - 外圈：蓝灰 `#4a5a6a` 矿区，岩石多、野狼刷新点。
- 实体：松树（25 棵）、岩石（20 块）带用户数据 `{kind, ent}`，悬停/射线共用。

### 4.2 单位（`entities/unit.ts`）
- `PioneerUnit` 类：拓荒者与野狼共用，行为由 `task` 状态机驱动（移动/采集/攻击/战斗/倒地）。
- Kenshi 式部位：`limbs {head, torso, armL, armR, legL, legR}`，任一归零 → `down` 倒地，几秒后复原。
- 视觉识别（可读性改造）：拓荒者高饱和衣服（橙红/蓝/紫）+ 帽子 + 手里举工具 + 选中金色旋转菱形标记；野狼红棕 + 大尖耳 + 亮红眼 + 深色脊背。

### 4.3 农田（`systems/farm.ts`）
- 地块状态机：`0 空地 → 1 已播种 → 2 生长中 → 3 成熟`。
- 成熟地块 `#99aa22` 金黄并带麦穗（三根细柱），一眼可辨可收获。

### 4.4 建造（`systems/build.ts`）
- 围栏：低矮木桩，圈定据点视觉边界。
- 木屋：半开式结构，`nearBuilding` 判定范围内角色缓慢回血。

### 4.5 战斗（`systems/combat.ts`）
- 野狼 AI：游荡（随机目标）→ 探测到玩家进入射程 → 追击 → 攻击（间隔 1 秒，伤害 8~12）→ 玩家反击互相掉血。
- 击杀有 30% 概率掉肉（+食物）；野狼到上限/时间刷新。

### 4.6 经济与贸易（`systems/economy.ts` + `ui/trade.ts`）
- 游商帐篷（紫色 + 金色球 + 暖光点光源）常驻世界中心附近，右键开启贸易面板。
- 出售食物 / 购买种子，面板实时刷新持有金币。

### 4.7 UI（`ui/`）
- HUD：右上资源栏（金币/木材/石头/食物/种子）、左下选中角色面板（血条/饥饿/部位）、右下日志、底部模式切换（数字键）、顶部新手提示。
- 悬停提示：指针指到任何实体显示「是什么 · 能干嘛」（树/岩/狼/商人/农田/建筑全覆盖）。
- 触摸等价路径：点击 = 选中 + 命令二合一（`touchAction`）。

## 5. 视觉设计

- 主光：定向光（暖白）+ 环境光，低多边形卡通风格。
- 雾：`#c8ccb8` 淡雾，远景分层拉开景深。
- 色板集中在 `PALETTE`（`config.ts`），实体颜色与地面分区严格区分，避免「一锅粥」。
- 不做阴影（移动端性能预算内），用明暗分区 + 雾表达层次。

## 6. 架构设计

- 单向数据流：`config.ts`（数值）→ `state.ts`（运行时状态）→ 各 `systems`（纯逻辑）→ `ui`（渲染 DOM）。
- 模块职责：`core`（渲染/世界/输入基础设施）、`entities`（单位）、`systems`（玩法规则）、`ui`（界面）。
- `commands.ts` 是输入→规则的唯一分发口，后续加技能/物品只需扩展 `commandAt`。
- 依赖方向：`systems → state/config`；`ui → state/systems`；`core` 不依赖玩法（除 world 的实体注册）。

## 7. 验证记录

- 2026-10-22：`tsc --noEmit` 0 错误；`vite build` 通过（dist ≈ 486 KB / gzip ≈ 127 KB）。
- 渲染验证方法（headless Firefox + 像素采样）：页面内同步 `renderer.render` 后 `glc.readPixels` 采样 5 点写入 DOM 诊断文本，headless 截图 OCR 读取。结果 `px: 77-36-114 | 46-68-32 | 170-184-142 | 57-87-35 | 48-74-28` —— 紫色（角色）、深绿（树冠）、浅色（远景）、草绿×2（地块），与单 HTML 版一致，确认场景/角色/地块渲染正确。
- 期间修复：重构时遗漏 `renderer.domElement` 挂载（canvas 不在 DOM），诊断文本 `no-gl-ctx` 暴露后修复。

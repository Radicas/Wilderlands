# Wilderlands · 游戏设计文档（GDD v0.4）

## 1. 概念

**一句话**：在低多边形的荒野上，开局独自一人（罗恩），采集、种田、建造、战斗、贸易，队友靠条件门招募争取，从一穷二白到站稳脚跟的沙盒生存游戏。

**定位关键词（主人定义）**：沙盒 · 种田 · 养殖 · 生存 · 荒诞 · 团队管理

**设计支柱**：

| 支柱 | 在本作中的体现 | 状态 |
| --- | --- | --- |
| 沙盒 | 右键语境命令：点哪干哪，无任务线 | ✅ 已有 |
| 种田 | 播种 → 生长 → 收获的经济正循环 | ✅ 已有 |
| 养殖 | 驯养动物（看门狼/下蛋鸡…），喂食与产出 | 🚧 规划 |
| 生存 | 饥饿、受伤、倒地恢复、昼夜与野狼威胁 | ✅ 已有 |
| 反馈 | 资源进包飘字、资源消亡动画、干活状态条（HUD）——劳作即时可感 | ✅ 已上线（change `gather-feedback`） |
| 生命感 | 转向补间不闪现、待机呼吸/环视、倒地倾侧渐入、狼摆尾炸耳、工具按活计换形；树冠放大不挡拾取（非树优先） | ✅ 已上线（change `unit-animation`） |
| 荒诞 | 世界有自己的古怪逻辑：设定/事件/文案带黑色幽默，自洽但不正经 | ✅ S4 落定（倒扣的破船 + 狼船长；更多事件待贯穿） |
| 团队管理 | 队员是"人"：性格、职责分工、养成分工 | 🚧 部分交付：性格三维度/情绪/闲时自治/当前行为可视化已上线（change `character-ai`）；职责分工与养成规划中 |

**荒诞基调**（本作区别于严肃生存沙盒的味道）：
- 世界观传说可以很离谱：野狼是迷路的宠物狗变的、浆果吃了会短暂看见幻觉、商人推着独轮车卖"会唱歌的石头"。
- 荒谬但自洽：世界不解释，玩家接受它就是这样。
- 文案载体：新手提示、物品描述、事件播报、队员碎碎念。

**体验目标**：前 10 分钟即进入「采集 → 种田 → 交易」的正反馈环；单位是可感知的个体（部位受伤、倒地、饥饿、性格），而不是无脑棋子。

## 2. 核心循环

```
采集(树/岩) → 建据点(围栏/木屋) → 种田(买种子→种→收)
        ↑                              ↓
    防御野狼 ←—— 卖出食物换金币 ——→ 扩大再生产
```

单次经济闭环（可复算）：`买种子 2 金 → 收获 2 食物 → 卖出 6 金`。玩家必须循环：种子产出食物、食物换金币、金币买种子与建材。

## 3. 数值设计（`src/config.ts` 为唯一数据源）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 起始金币（公共） | 20 | 货币不进背包、不占负重 |
| 初始背包（罗恩单人开局） | 木材3 / 石头2 / 食物3 / 种子1 | START_PARTY=1；队友靠招募条件门争取，合计随队伍成长 |
| 背包容量 / 物品重量 | 40 单位；木材/石头 2，食物/种子/浆果 1 | 负重 = Σ数量×重量；转移/丢弃一次 1 个 |
| 超载阈值 / 减速 | 负重 ≥80% / 移动 ×0.8 | 带多少物资要有决策分量 |
| 食物卖出价 / 种子买入价 | 3 金 / 2 金 | 单循环利润率 200%，节奏紧凑 |
| 木材/石头卖出价 | 1 金 / 1 金 | 采集物出口，经济闭环多一条腿 |
| 木矛价格 / 攻击加成 | 8 金 / +3 | 游商武器，装备给选中角色（可复算：3 轮种田闭环） |
| 流浪者招募条件 / 补位时间 | 1 座木屋 + 全队口粮≥5 + 25 金 / 60 秒 | "人很贵"：先熬过磨砺才谈组队（recruit.ts 单一条件源，前后端共用）；新队员空背包入队 |
| 浆果丛数量 / 产出 / 重生 | 14 丛 / +2 浆果 / 30 秒 | 浆果可当口粮（F 优先吃食物、不够吃浆果） |
| 农田生长时间 | 12 秒 | 一次收获 ≈ 一轮聊天的时间 |
| 昼夜时长 / 夜晚判定 | 240 秒 / t ≥ 0.5 | 约 2 分钟白昼 + 2 分钟夜晚 |
| 自动存档间隔 | 60 秒 | 静默写入自动槽 |
| 单位速度 | 0.04（世界单位/帧） | 与地图尺寸（40×40）匹配 |
| 部位血量 | 头/躯干/双臂/双腿各 100 | 部位化身体系统，为后续残疾系统留接口 |
| 饥饿速率 | 每秒 -0.05 | 从 100 饿到 0 约 33 分钟（长局友好） |
| 野狼刷新 | 上限 6 只，白天 26 秒 / 夜晚约 14 秒一只 | 夜晚更凶，保证压力但不淹没玩家 |

## 4. 系统设计

### 4.1 世界（`core/world.ts`）
- 40×40 世界，`PlaneGeometry` 地面 + 2×2 农田格（BoxGeometry 20×20 格）。
- **地形三区分区**（用户反馈「画面分不清」后的核心视觉决策）：
  - 内圈（距原点 < 8）：草绿 `#5a7a48` 家园区，出生与据点；
  - 中圈（< 18）：黄褐 `#6a5a3a` 野地，树木与岩石密集；
  - 外圈：蓝灰 `#4a5a6a` 矿区，岩石多、野狼刷新点。
- 实体：松树（25 棵）、岩石（20 块）、**浆果丛（14 丛，野地/矿区边缘）**、**流浪者（商站旁，可招募）** 带用户数据 `{kind, ent}`，悬停/射线共用。

### 4.2 单位（`entities/unit.ts`）
- `PioneerUnit` 类：拓荒者与野狼共用，行为由 `task` 状态机驱动（移动/采集/攻击/战斗/倒地）。
- 部位化身体：`limbs {head, torso, armL, armR, legL, legR}`，任一归零 → `down` 倒地，几秒后复原。
- 视觉识别（可读性改造）：拓荒者高饱和衣服（橙红/蓝/紫/**绿=第4名招募队员**）+ 帽子 + 手里举工具 + 选中金色旋转菱形标记；野狼红棕 + 大尖耳 + 亮红眼 + 深色脊背。
- **木矛**：装备后攻击 +3（5→8），矛杆加长、矛尖加粗变色；野狼与拓荒者共用攻击任务，拓荒者先走站位点再围殴，避免叠位。

### 4.3 农田（`systems/farm.ts`）
- 地块状态机：`0 空地 → 1 已播种 → 2 生长中 → 3 成熟`。
- 成熟地块 `#99aa22` 金黄并带麦穗（三根细柱），一眼可辨可收获。

### 4.4 建造（`systems/build.ts`）
- 围栏：低矮木桩，圈定据点视觉边界。
- 木屋：半开式结构，`nearBuilding` 判定范围内角色缓慢回血。

### 4.5 战斗（`systems/combat.ts`）
- 野狼 AI：游荡（随机目标）→ 探测到玩家进入射程 → 追击 → 攻击（间隔 1 秒，伤害 8~12）→ 玩家反击互相掉血。
- 击杀有 30% 概率掉肉（+食物）；野狼到上限/时间刷新。
- **修复**：刷怪半径修正为 22~30 世界单位（家园区 20 单位之外），并避开树/岩石；野狼注册进可交互射线目标（右键攻击 / 悬停提示可用）；死亡后从交互列表清除。
- **夜晚增强**：侦测距离 11→18、移动 ×1.15、刷新间隔 ×0.55。

### 4.6 经济与贸易（`systems/economy.ts` + `ui/trade.ts`）
- 游商帐篷（紫色 + 金色球 + 暖光点光源）常驻世界中心附近，右键开启贸易面板。
- 出售食物 / 木材 / 石头，购买种子 / 木矛；所有买卖作用于**选中首位角色的背包**（未选中提示「先选中一名拓荒者再交易」）。
- `F` 进食：从选中首位背包扣食物喂所有选中者（每人 1 份，饥饿 +50）；食物不够时自动吃浆果兜底。

### 4.7 招募与野外采集
- **流浪者**：商站旁斗篷兜帽 NPC；右键招募需过"人很贵"条件门——**1 座木屋（屋顶）+ 全队口粮（食物+浆果）≥5 + 公共金币 25**，三项缺一不可，缺什么日志点名提示；达成后花费 25 金招募为新拓荒者（空背包入队），招募后 60 秒新流浪者出现。条件判定在 `src/systems/recruit.ts` 纯函数单一来源，前端与 sim 共用。
- **浆果丛**：野外 14 丛，右键采集 +2 浆果（独立物品，可当口粮），采空 30 秒重生。

### 4.8 昼夜循环（`systems/daynight.ts`）
- 太阳沿轨道运行（240 秒/昼夜），光照强度/色温（早晚霞光）、天空与雾色渐变。
- HUD 右上显示时辰（清晨/正午/黄昏/夜晚/深夜）；夜晚野狼更凶（见 4.5）。

### 4.9 背包系统（`systems/inventory.ts`，v0.3）
- **模型**：金币 = 小队公共货币（不进背包）；资源物品 = 每人独立背包 `Inventory`（wood/stone/food/seed/berry），容量 40 单位，负重 = Σ数量×重量。
- **规则**：采集产物进干活者背包（装不下拒绝采集、资源留在原地）；建造/播种/进食/出售从选中首位背包扣；击杀野狼食物 +2 进击杀者背包；负重 ≥80% 移动 ×0.8。
- **唯一入口**：`invAdd / invRemove / transferItem`（增删/转移/丢弃全带容量校验与提示），所有玩法系统不得直接改背包。

### 4.10 存档系统（`systems/save.ts` + `ui/save.ts`，v0.3）
- **数据**：SaveData v1（`version` 必带）：金币/时辰/队员（位置/血量/饥饿/背包/木矛）/建筑/农田状态/流浪者。树/岩石/浆果不存档（读档重置重生成），野狼不存档（读档后重新刷 3 只）。
- **槽位**：自动槽（60 秒静默）+ 手动 1~3；键 `wilderlands.save.{auto,manual1..3}`。
- **读档流程**：写 `wilderlands.save.pending` → `location.reload()` → 启动时 `applySave`（读档校验 `migrateSave`，版本不符回退新开局并提示）。
- **迁移**：`migrateSave` 当前只接受 v1；未来加字段在此函数内逐级迁移。
- **导出/导入**：Blob 下载 JSON / 文件导入（校验通过后写入自动槽 + 待读标记 + 刷新）。

### 4.11 UI（`ui/`）
- HUD：右上资源栏（时辰/金币/小队合计：木材/石头/食物/种子/浆果）、左下选中角色面板（血条/饥饿/部位/**背包负重条 + 物品行 + 转移按钮**）、右下日志、底部模式切换（数字键）、顶部新手提示。
- 转移交互：背包行 `→` → 浮层列出其他队员（含负重百分比）+ 丢弃，点击即转移 1 个。
- 存档菜单：左上「存档」→ 4 槽位卡片（保存/读取/时间戳）+ 导出/导入 JSON。
- 悬停提示：指针指到任何实体显示「是什么 · 能干嘛」（树/岩/狼/浆果/流浪者/商人/农田/建筑全覆盖）。
- 触摸等价路径：点击 = 选中 + 命令二合一（`touchAction`）。

## 5. 视觉设计

- 主光：定向光（暖白）+ 环境光，低多边形卡通风格。
- 雾：`#c8ccb8` 淡雾，远景分层拉开景深。
- 色板集中在 `PALETTE`（`config.ts`），实体颜色与地面分区严格区分，避免「一锅粥」。
- 不做阴影（移动端性能预算内），用明暗分区 + 雾表达层次。

## 6. 架构设计

- 单向数据流：`config.ts`（数值）→ `state.ts`（运行时状态）→ 各 `systems`（纯逻辑）→ `ui`（渲染 DOM）。
- 模块职责：`core`（渲染/世界/输入基础设施）、`entities`（单位）、`systems`（玩法规则）、`ui`（界面）。
- `commands.ts` 是输入→规则的唯一分发口，后续加技能/物品只需扩展 `commandAt`。
- 依赖方向：`systems → state/config`；`ui → state/systems`；`core` 不依赖玩法（除 world 的实体注册）。
